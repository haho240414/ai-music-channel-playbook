# Thumbnail prompt template

Three prompts per episode: the cover plate, the clean plate, and the loop.

## 1. Cover plate

```
<STYLE LINE from character bible>. <CHARACTER PROMPT BLOCK, verbatim>, <what they are
doing> in <light condition>.

Background: <grounded scene detail 1>, <grounded scene detail 2>, <grounded scene
detail 3>, <atmospheric detail matching the season>.

Color palette: <brand colors> — no <excluded color families>.

Composition: character on the <SIDE>, generous negative space on the <OPPOSITE SIDE> for
title text.

No <landmark clichés>, no <style drift terms>, no extra foreground characters.
No generated lettering, no readable signage, no logo, no watermark.
<LIGHT DESCRIPTION>. 16:9 thumbnail composition.
```

## 2. Clean plate (no character, for loop backgrounds)

```
16:9 clean textless <STYLE> background plate for a seamless loop video: <scene>,
<grounded detail>, <grounded detail>, <season and light>. <Palette>. No title, captions,
logo, readable signage, characters, or watermark.
```

## 3. Loop

```
Create a 12-second seamless loop. Locked eye-level camera, no cuts, no zoom, no parallax
jump. Animate only <motion 1>, <motion 2>, and <motion 3>. Keep <everything that must
stay stable> stable. First and last frames must match. No text, logo, fake readable
signage, sudden weather change, or dramatic action.
```

Naming exactly what may move is what keeps the loop from breathing or morphing. Everything
not listed should be declared stable.

## Title layer (added afterward, never generated)

```
<EPISODE MOOD TITLE>
<GENRE · PLAYLIST>
```

- Real typeface, added as a separate layer over the reserved space
- Reserve 40–45% of the frame width
- No episode number on the thumbnail

## Season checklist

Every item must match the music, not just look nice:

- [ ] Foliage state
- [ ] Light quality and shadow hardness
- [ ] Clothing weight
- [ ] Seasonal props
- [ ] No track title in the episode contradicts the season shown

## Grounding checklist

- [ ] Two or three **specific** architectural or environmental nouns, not adjectives
- [ ] The named landmark is **excluded**, not featured
- [ ] Background fills at least half the frame
- [ ] Character is on the series' fixed side
