description: Plan a new episode — brief, season, sound ratio, and a tracklist with keys and BPM
---

Read `templates/episode-brief.md` and `examples/01-episode-brief.md`.

If the user has not given you the channel identity (genre, place, character, palette),
ask for it before planning. If they have an existing brief from a previous episode, work
from that instead so the channel stays consistent.

Then produce a filled episode brief with:

- Season and time of day fixed explicitly — both music and cover art will inherit them
- A global prompt: shared identity plus a negative list covering voice terms, adjacent
  genres the generator will drift into, and production clichés
- A tracklist of 12–15 with **BPM and key planned up front** so the episode can be
  sequenced harmonically afterward
- A hook instrument and arrival time in seconds for every track
- If the channel has a recurring motif, assign it to 2–3 tracks only

Check before finishing: does any track subject contradict the season?
