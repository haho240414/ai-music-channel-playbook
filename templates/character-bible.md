# Character bible — <SERIES NAME>

Copy the **Prompt block** verbatim into every cover prompt. Do not paraphrase it — that is
how a recurring character drifts into a different person over ten episodes.

## Identity

| Field | Value | Notes |
|---|---|---|
| Age band | | "early-to-mid 20s", not "young" |
| Hair | | Length, color, and the distinguishing detail |
| Expression | | Default emotional register |
| **Fixed prop** | | The silhouette element that identifies them at thumbnail size |
| Supporting props | | Occasional, not every episode |
| Clothing impression | | Color family, not a specific outfit |
| Frame position | | Same side every episode |

> The fixed prop matters more than the face. At thumbnail scale a face is ~40px tall and
> unrecognizable; a distinctive silhouette element is what makes an episode identifiable
> in a subscription feed.

## Prompt block

```
Same recurring character: a <AGE BAND> <PERSON>, <HAIR>, <EXPRESSION>, wearing
<CLOTHING IMPRESSION> with <FIXED PROP>, positioned on the <SIDE> side of the frame.
```
